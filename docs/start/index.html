01//Quickstart

60 seconds, 0 dependencies

Run one full loop first.

The demo runs all 5 loop steps on one small case: a forged bound, a steelman on W plus W-perp, a clean room second check with a sharpness wall, a higher moment fix and mutation catches.

git clone https://github.com/Foundation-0/aletheia.git
cd aletheia
python3 -I -O -B -W error examples/worked_resonance_cycle/run_demo.py

Then run the self test suite in all 3 required modes. All 3 must agree under R4.

python3 -I -B tests/run_all.py && python3 -I -O -B tests/run_all.py && python3 -I -B -W error tests/run_all.py

02//Command line

aletheia v2.0.0

One program for the full loop.

Run the program with no install, or install it with pip install -e . from the repo root.

# Help, with no install
PYTHONPATH=. python3 -m aletheia --help

# Scaffold a new expedition workspace
PYTHONPATH=. python3 -m aletheia init /tmp/my-expedition --domain physics

# Audit this repo: 3 mode parity, bare asserts, strict JSON, leaks and Lean purity
PYTHONPATH=. python3 -m aletheia audit-check . --strict-ancestors

# Gate contract self test: R6 and R7, R3 both ways, NOT_SHOWN, Gate 8 latch, Law 2b, Own-Terms-First
PYTHONPATH=. python3 -m aletheia gate-v2 --self-test --json

# Static safety scan on package code
PYTHONPATH=. python3 -m aletheia safety-scan aletheia --json

# Mutation test a verifier and prove each guard can still say no
PYTHONPATH=. python3 -m aletheia mutate path/to/verifier.py --work-root . --add-cwd --max-mutants 0 --test-cmd "python3 path/to/tests.py"

# Diagnose relapse patterns CS-01 to CS-12 in a workspace
PYTHONPATH=. python3 -m aletheia diagnose /tmp/my-expedition

# List, run and self test the 8 glyph operator calculus
PYTHONPATH=. python3 -m aletheia calculus --list --json
PYTHONPATH=. python3 -m aletheia calculus --eval "⦺(L_odd ⦷ chi1) ⩩ (1, 2, 1)" --json
PYTHONPATH=. python3 -m aletheia calculus --self-test --json

Two more demos ship in the same program: aletheia ratchet --demo and aletheia mde --demo. See --help for flags.

04//Workspace

What init writes

One folder per role.

The init command writes a small workspace with fixed read and write scopes per role. It refuses to overwrite files in place. Pass --force only when you mean to replace them.

PYTHONPATH=. python3 -m aletheia init /tmp/my-expedition --domain physics
PathRole and use
aletheia.jsonWorkspace config: schema, domain, role scopes and the 3 R4 modes.
cartography/Portal keeper writes here and loops all run. Holds frontier_portals.md.
probes/<domain>/Domain probe writes here. Reads cartography and peer-web.
synthesis/Synthesizer writes here. Reads cartography, probes and peer-web.
peer-web/Peer weaver writes here for cross front links.
verification/Verifier writes here. Holds PROTOCOL.md and AUDIT_LOG.md, with check scripts in verification/checks/.
manifests/Holds compute_handoff.v1.json for pinned handoffs.

Keep the keeper in cartography for the whole run. That one habit is Law 1. Test claims from probes and let verification hold its own write scope with no shared code.
