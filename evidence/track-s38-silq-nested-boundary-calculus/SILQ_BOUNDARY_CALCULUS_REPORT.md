## Pillar 1 — Exact Dyadic Cyclotomic Ring $\mathbb{D}[i, \sqrt{2}] = \mathbb{Z}[\frac{1}{2}, \sqrt{2}, i]$ (`Clifford + T` Arithmetic)

1. **Exact Ring Representation (Kliuchnikov–Maslov–Mosca 2013; Giles–Selinger 2013 `N0`):** Every quantum amplitude is represented without floating-point approximation as an exact 4-tuple $(a, b, c, d) \in \mathbb{Q}^4$ denoting
   $$z = (a + b\sqrt{2}) + i(c + d\sqrt{2}), \qquad |z|^2 = z\bar{z} = (a^2 + 2b^2 + c^2 + 2d^2) + 2(ab + cd)\sqrt{2} \in \mathbb{Q}[\sqrt{2}].$$
   In particular, $\frac{1}{\sqrt{2}} = (0, \frac{1}{2}, 0, 0)$ and $\omega_8 = e^{i\pi/4} = (0, \frac{1}{2}, 0, \frac{1}{2})$, so the entire `Clifford + T` gate set lies strictly inside $\mathbb{D}[i, \sqrt{2}]$ (all denominators powers of `2`).
2. **Unitarity & Group Relations Certified Live:**
   - All **9/9** certified gates (**`X`, `Y`, `Z`, `H`, `S`, `T`, `CNOT`, `CZ`, `CCX`** — note: `CZ`, not `I`, correcting the PR `#37` description) satisfy exact unitarity $U^\dagger U = I$ (hence $U U^\dagger = I$ for finite square matrices over $\mathbb{Q}(\sqrt{2}, i)$) and exact dyadic membership.
   - All **14/14** group relations verified by exact matrix multiplication: `X^2 = I`, `Y^2 = I`, `Z^2 = I`, `H^2 = I`, `T^2 = S`, `S^2 = Z`, `T^4 = Z`, `T^8 = I`, `H X H = Z`, `H Z H = X`, `CNOT^2 = I`, `CZ^2 = I`, `(I ⊗ H) CNOT (I ⊗ H) = CZ`, `CCX^2 = I`.
   - **Negative control:** Non-unitary shear `[[1, 1], [0, 1]]` is cleanly rejected (`is_unitary_cyc == False`).
3. **Exact Born Probability Conservation (Zero Floats):** All 4 witnesses satisfy exact unit norm `(sum_q, sum_sqrt2) = (1, 0)` and exact algebraic non-negativity $u + v\sqrt{2} \ge 0$:
   - `bell_pair` ($\text{CNOT}(H \otimes I)|00\rangle$): `[1/2, 0, 0, 1/2]`.
   - `magic_HTH_ket0` ($H T H |0\rangle$): $P(|0\rangle) = \frac{1}{2} + \frac{1}{4}\sqrt{2}$, $P(|1\rangle) = \frac{1}{2} - \frac{1}{4}\sqrt{2}$ (exact positivity $\frac{1}{4} \ge \frac{1}{8}$, exact sum `(1, 0)`).
   - `ghz_3q`: `[1/2, 0, 0, 0, 0, 0, 0, 1/2]`.
   - `toffoli_superposed` ($\text{CCX}(H \otimes H \otimes I)|000\rangle$): `[1/4, 0, 1/4, 0, 1/4, 0, 0, 1/4]`.

## Pillar 2 — Toy 7-Operation Dictionary IR Modelled on Silq Annotations (`!B`, `B`, `const`, `qfree`, `lifted`, `mfree`, `forget`, `measure`)

`typecheck_silq_program` is a **small toy IR checker modelled on Silq's annotations** (Bichsel et al., PLDI 2020 `N0`). It parses **no Silq source syntax** and is **not** the `silq-lang/silq` compiler/type-checker; it checks a 7-operation Python dictionary IR (`alloc_q`, `lifted_and`, `qfree_gate`, `unitary_gate`, `dup`, `measure`, `forget`) over two wire types (`!B`, `B`) on 13 hand-written IR programs:

- **Classical `!B` vs Linear Quantum `B` (Intentional Toy-IR Deviation from Silq Subtyping):** Classical `!B` variables may be duplicated (`dup`) and dropped; quantum `B` variables forbid cloning (`QUANTUM_CLONING_FORBIDDEN`) and silent dropping (`UNCONSUMED_QUANTUM_DROP`). Unlike full Silq (PLDI 2020), whose subtyping rule `!τ <: τ` lets classical `!B` values appear wherever quantum `B` operands are expected, this toy IR enforces strict `B` operands on `lifted_and`, `qfree_gate`, and `unitary_gate` (rejecting `!B` operands with `TYPE_MISMATCH`).
- **`qfree`, `lifted`, and `mfree`:** `qfree` permits basis operations (`X`, `CNOT`, `CCX`, `lifted_and`) and rejects `unitary_gate` (`NON_QFREE_OP_IN_QFREE`) and `measure` (`MEASURE_IN_MFREE_OR_QFREE`). `lifted` additionally requires every quantum parameter to be `const` (`LIFTED_REQUIRES_CONST_QPARAMS`). `mfree` permits `unitary_gate` (`H`, `Y`, `Z`, `S`, `T`, `CZ`, `phase`) and rejects `measure`.
- **`const`, Control Arity & Restricted `lifted_and` Uncomputation:** Exact gate control arities (`X`/`Y`/`Z`/`H`/`S`/`T`/`phase`: `0`, `CNOT`/`CZ`: `1`, `CCX`: `2`) are enforced (`GATE_ARITY_MISMATCH`). Both `qfree_gate` (`CNOT`, `CCX`) and diagonal `unitary_gate` (`CZ`) consistently allow `const B` controls while rejecting `const B` targets (`CONST_MODIFICATION_FORBIDDEN`), as well as returning or measuring a `const B` parameter (`CONST_CONSUMPTION_FORBIDDEN`); single-qubit phase gates (`Z`, `S`, `T`, `phase`) and `CZ` targets on a `const B` wire remain rejected in this toy IR. Automatic uncomputation is restricted solely to `lifted_and` temporaries (`tmp := a & b`, synthesizing `CCX(a,b,tmp)`) whose dependencies `(a, b)` and `tmp` itself were not mutated by a `qfree` or non-diagonal gate (`UNCOMPUTATION_FAILED` on explicit `forget`, `UNCONSUMED_QUANTUM_DROP` on block exit).

## Pillar 3 — Exact Partial-Trace Purity Witnesses for Uncomputed vs. Retained Ancillae

For two finite exact bipartite states $|\Psi\rangle_{OH}$ over $\mathbb{D}[i, \sqrt{2}]$, `build_pillar3_uncomputation_partial_trace` evaluates exact reduced density matrices $\rho_O = \operatorname{Tr}_H(|\Psi\rangle\langle\Psi|)$, exact purity $\operatorname{Tr}(\rho_O^2) \in \mathbb{Q}$, and exact linear entropy $S_L(\rho_O) = 1 - \operatorname{Tr}(\rho_O^2) \in \mathbb{Q}$ (confirming Hermiticity $\rho_O^\dagger = \rho_O$, $\operatorname{Tr}(\rho_O) = 1$, and zero imaginary/$\sqrt{2}$ parts):

| Finite Witness & Ancilla Handling | $\dim(\rho_O)$ | Exact Purity $\operatorname{Tr}(\rho_O^2)$ | Exact Linear Entropy $S_L$ | Exact Diagonal Probabilities | Observed Outcome |
| --- | --- | --- | --- | --- | --- |
| **Deutsch–Jozsa (`O=[0], H=[1]`) — Explicit manual uncompute `CNOT(0,1)`** | `2` | **`1`** | **`0`** | `["0", "1"]` | Pure state (`P(\|1>) = 1`) |
| **Deutsch–Jozsa (`O=[0], H=[1]`) — Retained entangled ancilla `H`** | `2` | **`1/2`** | **`1/2`** | `["1/2", "1/2"]` | Maximally mixed (`\rho_O = I/2`) |
| **3-Qubit Toffoli–Grover (`O=[0,1], H=[2]`) — Explicit uncompute `CCX(0,1,2)`** | `4` | **`1`** | **`0`** | `["0", "0", "0", "1"]` | Pure state (`P(\|11>) = 1`) |
| **3-Qubit Toffoli–Grover (`O=[0,1], H=[2]`) — Retained entangled ancilla `tmp`** | `4` | **`5/8`** | **`3/8`** | `["1/8", "1/8", "1/8", "5/8"]` | Purity reduced (`3/8` off-target weight) |

**Scope of Pillar 3:** These two finite matrix calculations verify directly that omitting the uncomputation gate before the final interference step lowers $\operatorname{Tr}(\rho_O^2)$ from `1` to `1/2` (Deutsch–Jozsa) and from `1` to `5/8` (Toffoli–Grover). `build_pillar3_uncomputation_partial_trace` applies explicit gate matrices via `apply_gate_state` and does **not** invoke `typecheck_silq_program` or prove a general equivalence theorem. In particular, the Deutsch–Jozsa witness's manual `CNOT(0,1)` uncompute is **outside** what Pillar 2's `lifted_and`-only toy checker accepts (passing `alloc_q H; H(O); CNOT(O->H); Z(H); forget(H); H(O)` to `typecheck_silq_program` returns `UNCOMPUTATION_FAILED`, verified in `test_silq_boundary_calculus_r5.py`), whereas the Toffoli `lifted_and` + diagonal `Z` + `forget(tmp)` pattern does pass Pillar 2's checker and synthesizes `CCX(a,b,tmp)`.

Pure-$\mathbb{Z}$ power inequalities $2^{19} = 524{,}288 < 27^4 = 531{,}441$ and $27^5 = 14{,}348{,}907 < 2^{24} = 16{,}777{,}216$ certify the exact rational bracket **`19/16 < H(X|Y) < 6/5`** bits (`1.1875 < 1.18872 < 1.2000`, zero floats).
   - **Irreversible 1-Bit Reset `ERASE` ($1 \to 1$):** Fibers `{0: 2}`, $2^{2 H(X \mid Y)} = 4 \implies H(X \mid Y) = 1$ exact bit ($\Delta Q_{\min} = k_B T \ln 2$).
