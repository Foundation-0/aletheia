## 2. How Round 6 Directly Evolved `Foundation-0/aletheia` (`v1.3.0` $\to$ `v1.4.0`)

Four concrete failure modes caught live across `AUDIT-061R`–`065` were reverse-extracted into permanent, zero-dependency gates inside `Foundation-0/aletheia` `v1.4.0`:

1. **AST Local Refusal-Wrapper Auto-Detection (`aletheia/mutator.py`, from `PR1-B4`):**
   - *Live Discovery:* `aletheia v1.3.0 mutate` reported `1/1 (100.0%)` on `bareiss_gram_gate.py` because `_REQUIRE_FUNC_NAMES` matched only fixed names (`require`, `require_ok`, ...) and missed all `51` calls to local helper `def _req(cond, code, msg): if not cond: raise ...`—hiding `53/74` surviving mutants (`28.38%` true kill rate).
   - *v1.4.0 Upgrade:* `discover_local_refusal_wrappers(tree)` runs an AST pre-pass detecting local single-refusal helper wrappers of both `"require"` polarity (`if not cond: raise ...`, mutating `arg0 -> True`) and `"reject"` polarity (`if cond: raise ...`, mutating `arg0 -> False`), handling optional docstrings, optional trailing `return`, and `self`/`cls` method receivers, and reporting `local_wrappers_detected` in `aletheia mutate --json`.
2. **Strict Duplicate-Key + No-`NaN` JSON/JSONL Loaders Everywhere (`aletheia/strict_io.py`, `audit_check.py`, `diagnose.py`, `calculus.py`, from `WD-LEDGER-01` & `WD-SERVER-01`):**
   - *Live Discovery:* Raw `json.loads()` silently overwrote duplicate keys (`"reason":"EVIL_DUPLICATE"`, shadowed `"signature"`), accepted non-RFC-8259 `NaN`/`Infinity`, and parsed whitespace-only tampered JSONL files as clean empty ledgers.
   - *v1.4.0 Upgrade:* Exported `loads_strict_json` and `load_strict_jsonl_file` from `aletheia`, eliminated remaining raw `json.loads()` calls in `diagnose.py` and `calculus.py`, and wired strict `.jsonl` verification (rejecting duplicate keys, `NaN`/`Infinity`, blank lines, and whitespace-only tampered files) directly into `aletheia audit-check`.
3. **Canonical Ancestor-Directory Permission Gate (`verify_ancestor_dir_modes`, `audit_ancestor_dir_permissions`, `--strict-ancestors`, from `harden-image-modes.sh` & `AUDIT-062R` `BYPASS-04`):**
   - *Live Discovery:* Hardening a leaf directory while leaving an ancestor directory group/world-writable (`mode & 0o022 != 0`) or omitting `/etc/warp` lets unprivileged actors rename-swap read-only verifier/policy files; non-canonical paths (`//etc/warp`, `..`, NUL) and `bool` modes (`False`) bypassed naive validators.
